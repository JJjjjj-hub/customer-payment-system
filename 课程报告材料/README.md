# 课程报告材料

本目录用于随项目进度持续维护《客户回款数据库系统》课程报告材料。当前内容是基于课程要求和已确认业务定义整理的设计初稿，不代表系统已经实现。完成接口联调和测试后，应将方案性文字改为真实实现，并补入实际截图、测试结果和备份恢复证据。

## 文件索引

- `报告初稿.md`：按 2026 报告要求编排的报告正文底稿。
- `报告初稿.docx`：可在 Word 中继续编辑的当前初稿。
- `数据字典与关系模式.md`：核心实体、字段建议及关系说明。
- `测试用例表.md`：按课程测试要求整理的待执行测试矩阵。
- `图稿/用例与业务流程.mmd`：可渲染的业务流程图源文件。
- `图稿/ER图.mmd`：可渲染的 ER 图源文件。
- `待补材料清单.md`：项目推进期间需要提供/采集的实际证据清单。

- [数据库与接口开发公约](../任务规划/数据库与接口开发公约.md)：可独立转发的统一字段、主外键、DDL、API、并发与幂等基线。

## 维护约定

1. 功能未完成前使用“设计方案/拟实现”等表述。
2. 每个完成阶段由 A/B 提供真实表结构、接口、截图和测试结果，再更新对应章节。
3. 报告最终目录依照 2026 年报告要求；备份恢复内容并入数据库实现或系统测试与运行部分。
4. 不虚构测试通过情况、运行截图、数据库版本或开发环境版本。
