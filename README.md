# customer-payment-system

客户回款数据库系统课程项目，采用 Java / Spring Boot / MySQL，规划实现客户、合同、应收款、回款核销及统计管理。

## 当前状态

本次提交包含课程原始资料、A/B 分工、数据库与接口开发公约、报告设计初稿及图表源文件。后端、前端尚未实现；报告中的待补内容不代表已完成或测试通过。

## 资料入口

- [数据库与接口开发公约](任务规划/数据库与接口开发公约.md)：表字段、主外键、DDL、REST API、金额口径、并发与幂等规则。
- [成员 A 任务](任务规划/成员A任务.md)：客户、合同、应收款与数据库设计。
- [成员 B 任务](任务规划/成员B任务.md)：回款、核销、统计与测试。
- [总体任务完成路径](任务规划/总体任务完成路径.md)：阶段、协作和验收。
- [课程报告材料索引](课程报告材料/README.md)：Markdown/Word 初稿、数据字典、测试用例表及 Mermaid 图稿。

仓库根目录的四份 Word 文件为课程指导书、课程说明、2026 报告要求和封面模板，保留原始文件名。

## 协作约定

当前资料提交在 `docs/course-materials` 分支。成员 A/B 以开发公约为共同基线，在各自功能分支推进；合并 `main` 需单独评审。本次不创建或合并 Pull Request。

后续代码建议放入 `backend/`、`frontend/`，数据库迁移随后端统一管理。数据库密码保存在未跟踪的本地配置中，仓库只保留无真实密码的配置示例。
